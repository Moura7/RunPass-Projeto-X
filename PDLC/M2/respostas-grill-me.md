## Proveniência e precedência

Fontes: histórico da entrevista e revisões, RUNPASS-CONTEXTO-E-DEFINICOES.md e PRD v2 aprovado. Este resumo aplica as confirmações mais recentes sobre regras anteriores: foto obrigatória sem imagem de catálogo; visibilidade inicial pública; prioridade a usuários seguidos; beta iniciado com 50, não 1.000; denominador real.

| Tema da entrevista | Resposta consolidada |
| --- | --- |
| Motivação | Rede social de corridas, medalhas, avaliações e troca de experiências. |
| Plataformas | Android e iPhone; site para usuários futuro. |
| Primeira rede | Corredores já conhecidos, sem limitar a descoberta a eles. |
| Descoberta | Área própria de catálogo, busca e provas futuras. |
| Prova ausente | Solicitação pelo usuário, revisão RunPass, participação em rascunho. |
| Conclusão | Apenas concluídas, autodeclaração, sem comprovante obrigatório. |
| Resultado | Tempo opcional; pode ocultar tempo/colocação; pace oculto junto ao tempo. |
| Unicidade | Uma participação por edição; várias edições podem ocorrer no mesmo ano. |
| Edição dos dados | Edição completa e exclusão dos próprios registros, inclusive troca de edição. |
| Conflito de edição | Editar o existente ou excluí-lo antes de nova adição; não duplicar. |
| Medalha | Automática, com imagem do catálogo; se ausente, exigir foto para concluir. |
| Foto do usuário | Vinculada ao próprio registro, não incorporada automaticamente ao catálogo. |
| Avaliação | Oito critérios obrigatórios, 1–5 estrelas, comentário opcional; obrigatória na conclusão. |
| Score | Média simples dos oito critérios e média das avaliações; por edição, uma casa decimal. |
| Distâncias | Filtrar reviews por distância, mantendo score geral da edição. |
| Correção da avaliação | Permitida, substituindo notas anteriores e recalculando score. |
| Exclusão da participação | Remove medalha, avaliação, post/interações e atualiza agregados. |
| Catálogo | RunPass mantém; IA futura. Capital, dois anos iniciais; aceitar solicitações mais antigas. |
| Tamanho do catálogo | Sem mínimo de 500; cobrir 90% das edições da lista de convidados. |
| Lista de referência | Primeiros convidados, edições distintas, lista/período congelados antes de medir. |
| Dados da solicitação | Nome, data, cidade e distância obrigatórios; link e imagem opcionais. |
| Duplicidade de prova | Vincular rascunho à edição existente, preservar dados, avisar, usuário revisa. |
| Recusa de solicitação | Motivo, correção e reenvio, preservando rascunho. |
| Feed | Conclusões e medalhas; curtidas/comentários; outros perfis/publicações acessíveis. |
| Prioridade | Quem o usuário segue tem prioridade de ordenação; não restringir aos seguidos. |
| Conteúdo inicial | Conquistas recentes de corridas da capital quando faltar contexto pessoal. |
| Publicação | Visível por padrão, ocultável no registro ou depois; participação continua no perfil. |
| Atualização de post | Editar existente, preservar interações, sem duplicar. |
| Encontrar conhecidos | Nome/username e link do perfil; sem importar contatos. |
| Perfil | Público; nome/username obrigatórios; foto/cidade/bio opcionais; e-mail privado. |
| Wishlist | Pública por padrão e ocultável; “Quero correr”. |
| Compartilhar | Cards e links; app ou loja correspondente, sem site público de conteúdo. |
| Avisos | Internos para revisão, seguidores e interações; sem push. |
| Bloqueio | Impedir novas interações e ocultar anteriores, sem excluí-las. |
| Moderação | Equipe humana, remoção de conteúdo/suspensão, justificativa registrada. |
| Notas invalidadas | Excluir do público/score, preservar participação/medalha/post; correção revisada. |
| Administração | Painel interno mínimo incluído; distinto de site para corredores. |
| Arquivar edição | Com participações, preservar histórico e referências; não apagar em cascata. |
| Beta | Gratuito, convidados maiores de 18 anos; meta e teto 1.000. |
| Prazo | 60 dias desde primeiros 50; não esperar completar 1.000. |
| Ativação | 50% dos admitidos reais com participação completa; ativo nessa visão = ativado. |
| Repetição | 30% dos ativados com segunda edição registrada. |
| Social | 30% dos ativados com like/comentário em conquista alheia, usuários únicos. |
| Feedback | Após registro, botão contínuo, 30/60 dias, sete dias sem registro; consolidar semanalmente. |
| Exclusões do escopo | Site público, push, marcos extras, rankings, clubes, monetização, GPS/treino e integrações avançadas. |
